# Week 3–6 design catalogue

Completed against the supplied assignment screenshots and the V.2 production manual. Week 1–2 artwork and resource values from the student’s Canva were retained.

## Week 3 forests

Resource scale: 0–5. Array order: Food, Sugar, Tobacco, Cotton, Fur, Lumber, Iron Ore, Silver. Values are proposed game balance, not measured historical data. Clearing mappings follow the assignment, not ecological laws.

### Conifer Forest

ป่าสนมีไม้ใบเข็ม เช่น สนและสปรูซ เป็นองค์ประกอบเด่น และมีโครงสร้างเรือนยอดต่างจากป่าใบกว้าง. พบได้ในเขตอบอุ่นและบริเวณภูเขาของอเมริกาเหนือ โดยชนิดของไม้ขึ้นอยู่กับภูมิอากาศและระดับความสูง.

Region: อเมริกาเหนือเขตอบอุ่นและแนวภูเขา
Clears to: Grassland
Resources: [2, 0, 0, 0, 3, 5, 1, 0]
Reference: https://research.fs.usda.gov/silvics/

### Broadleaf Forest

ป่าใบกว้างประกอบด้วยไม้ที่มีแผ่นใบกว้าง และในเขตอบอุ่นหลายชนิดผลัดใบตามฤดูกาล. พบในภาคตะวันออกของอเมริกาเหนือและเขตอบอุ่นชื้น โดยไม่ได้หมายความว่าทุ่ง Prairie ทุกแห่งเคยเป็นป่า.

Region: อเมริกาเหนือตะวันออกและเขตอบอุ่นชื้น
Clears to: Prairie
Resources: [3, 0, 0, 0, 3, 4, 1, 0]
Reference: https://research.fs.usda.gov/silvics/

### Savanna Woodland

พื้นที่ป่าโปร่งชนิดนี้มีต้นไม้กระจายอยู่เหนือชั้นหญ้า และมีช่องเปิดมากกว่าป่าทึบ. พบในเขตร้อนที่มีฤดูกาลชัดเจน รวมถึงบางส่วนของอเมริกาใต้ โดยความหนาแน่นของไม้ขึ้นกับน้ำและไฟในระบบนิเวศ.

Region: อเมริกาใต้เขตร้อนและพื้นที่ฤดูแล้งชัดเจน
Clears to: Savannah
Resources: [1, 1, 0, 0, 1, 3, 2, 0]
Reference: https://home.nps.gov/subjects/nnlandmarks/tropical-ecosystems.htm

### Mixed Forest

ป่าผสมมีทั้งไม้ใบเข็มและไม้ใบกว้างอยู่ร่วมกัน ทำให้เรือนยอดและการเปลี่ยนแปลงตามฤดูกาลมีความหลากหลาย. พบในบริเวณเปลี่ยนผ่านของป่าเขตอบอุ่นและเขตหนาว เช่น รอบเกรตเลกส์และภาคตะวันออกเฉียงเหนือของอเมริกาเหนือ.

Region: รอบเกรตเลกส์และตะวันออกเฉียงเหนือของอเมริกาเหนือ
Clears to: Plain
Resources: [2, 0, 0, 1, 3, 4, 1, 0]
Reference: https://research.fs.usda.gov/silvics/

### Boreal Forest (Taiga)

ไทกาเป็นป่าของละติจูดสูงที่มีไม้ใบเข็มทนหนาวเป็นส่วนสำคัญ และมีฤดูเติบโตค่อนข้างสั้น. พบกว้างขวางในแคนาดา อะแลสกา และยูเรเชีย โดยขอบด้านเหนือเป็นแนวเปลี่ยนผ่านเข้าสู่ Tundra.

Region: แคนาดา อะแลสกา และยูเรเชียตอนเหนือ
Clears to: Tundra
Resources: [0, 0, 0, 0, 4, 3, 2, 0]
Reference: https://research.fs.usda.gov/treesearch/64446

### Scrub Forest

ป่าละเมาะแห้งมีไม้พุ่มและไม้เตี้ยที่ทนต่อการขาดน้ำ โดยมักมีเรือนยอดไม่ต่อเนื่อง. พบในพื้นที่กึ่งแห้งแล้งและขอบทะเลทราย เช่น บางส่วนของเม็กซิโกและตะวันตกเฉียงใต้ของอเมริกาเหนือ.

Region: เม็กซิโกและอเมริกาเหนือตะวันตกเฉียงใต้
Clears to: Desert
Resources: [0, 0, 0, 0, 1, 1, 3, 3]
Reference: https://home.nps.gov/subjects/nnlandmarks/tropical-ecosystems.htm

### Tropical Rainforest

ป่าดิบชื้นมีเรือนยอดหลายระดับและพืชหลากหลายชนิดในสภาพอากาศอุ่นชื้น. พบในอเมริกากลางและลุ่มน้ำแอมะซอน แต่ไม่ได้เป็นพื้นที่น้ำขังทั้งหมด โดยการถางแล้วเป็น Swamp เป็นกติกาจำลองตามงานนี้.

Region: อเมริกากลางและลุ่มน้ำแอมะซอน
Clears to: Swamp
Resources: [1, 1, 0, 0, 2, 5, 0, 0]
Reference: https://home.nps.gov/subjects/nnlandmarks/tropical-ecosystems.htm

- 06 Farmer (ชาวนา): จอบและข้าวโพด
- 07 Fisherman (ชาวประมง): แหและปลา
- 08 Lumberjack (คนตัดไม้): ขวานและท่อนไม้
- 09 Carpenter (ช่างไม้): ค้อนช่างไม้และแผ่นไม้
- 10 Ore Miner (ชาวเหมืองแร่): พลั่วและตะกร้าแร่เหล็ก

- 12 Fur Trapper (พรานดักสัตว์): หนังสัตว์และกับดัก
- 13 Fur Trader (พ่อค้าขนสัตว์): มัดขนสัตว์และสมุดบัญชี
- 14 Cotton Planter (คนปลูกฝ้าย): ตะกร้าฝ้ายดิบ

- 16 Missionary (บาทหลวง): หนังสือและกางเขนไม้
- 17 Statesman (รัฐบุรุษ): เอกสารและปากกาขนนก
- 18 Gunsmith (ช่างทำปืน): พานท้ายปืนและตะไบ
- 19 Criminal (นักโทษ): เสื้อผ้าธรรมดาและโซ่ตรวน

## Week 5 ships

- Caravel: เรือสำรวจขนาดเล็ก คล่องตัว ใบเรือสามเหลี่ยมเด่น

- Man Of War: เรือรบขนาดใหญ่หลายชั้นปืน บทบาทกำลังรบหนัก

## Interpretation and implementation

- ค่าทรัพยากร อาชีพ Supply คู่แข่ง และระดับ Aggression เป็นการออกแบบเกม ไม่ใช่ลักษณะประจำชนชาติหรือข้อเท็จจริงทางประวัติศาสตร์
- ธง Native ทุกแบบเป็นตราประจำฝ่ายที่ออกแบบใหม่ ไม่ใช่ธงประวัติศาสตร์หรือธงทางการของชุมชนปัจจุบัน
- ภาพผู้นำเป็นภาพตีความ CG สำหรับเกม ผู้นำสมมติระบุชัดเจนทุกหน้า
- Broadleaf→Prairie, Boreal→Tundra และ Rainforest→Swamp เป็นการแปลง Terrain ตามโจทย์ ไม่ใช่ข้อสรุปทางนิเวศวิทยา
- ฐานเกมใช้ชื่อ enum และ ScriptableObject เดิมเพื่อคงความเข้ากันได้

The 20 land entries and six ship entries are imported and referenced by the scene catalogue. The lecturer gameplay still starts with its original five land categories and Caravel. Extra professions and ships are asset/data catalogue entries; no new recruitment or profession gameplay was added.

Forest-specific resource tables and Native trade/relationship preferences are design specifications in this catalogue. The lecturer baseline has no corresponding independent fields or systems. Existing gameplay structure was retained; Week 7 production, menus, diplomacy and recruitment were not introduced.

Unit enum values 0–11 are preserved. Eight missing profession labels were appended so all 20 icons can be stored without mislabelled ScriptableObjects. Existing unit/ship statistics were preserved. New catalogue entries use clearly provisional basic game defaults.

All artwork added in this change was generated with the built-in image generation tool, except the retained student terrain images. PNG resizing/padding creates the required assignment sizes and the original prefab canvas dimensions. Source images were preserved.
